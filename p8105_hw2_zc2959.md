### Trash Wheel Data Description

1.  Before combining the data, Mr. Trash Wheel has 740 observations,
    Professor Trash Wheel has 137 observations, and Gwynnda has 392
    observations. After using `bind_rows()`, the combined `trash_wheel`
    dataset has 1269 observations, with each row representing one
    dumpster collection.

2.  The combined dataset includes key variables such as `wheel`,
    `dumpster`, `month`, `year`, `weight_tons`, `volume_cubic_yards`,
    `plastic_bottles`, and `cigarette_butts`. The `wheel` variable shows
    which Trash Wheel each observation comes from, while the other
    variables describe when the dumpster was collected and the amount or
    type of trash collected.

3.  After combining the three datasets, observations from all three
    Trash Wheels are stored in the same dataframe. Variables with the
    same name are combined into the same columns, while variables that
    were not recorded for every Trash Wheel contain missing values for
    those observations.
