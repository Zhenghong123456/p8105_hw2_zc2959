### Subway Data Description

1.  `transit_df` has 1868 rows and 19 columns, with each row
    representing one subway entrance or exit.

2.  The data include the station, line, location, routes served,
    entrance type, entry, vending, and ADA status. I kept the columns
    needed for the analysis and changed `entry` from YES / NO to TRUE /
    FALSE.

3.  The data are not tidy yet because the route information is spread
    across `route1` to `route11`.

## Reformatting data

``` r
transit_long = 
  transit_df |>
  mutate(
    across(route1:route11, as.character)
  ) |>
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name"
  )
```

``` r
n_a_stations = 
  transit_long |>
  filter(route_name == "A") |>
  distinct(line, station_name) |>
  nrow()

n_a_ada = 
  transit_long |>
  filter(route_name == "A", ada == TRUE) |>
  distinct(line, station_name) |>
  nrow()
```

1.  The A train serves 60 distinct stations.

2.  17 of the stations served by the A train are ADA compliant.
